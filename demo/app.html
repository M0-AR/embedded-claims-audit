Reproducibility

The verification loop

Every experiment returns a JSON payload. make verify re-runs all ten experiments and compares the fresh payload with the stored artifact field by field.

$ make verify
ok e01_sixstep
ok e02_svpwm
…
checked 10 experiment(s), 34,650 scalar field(s)
max relative difference 0.000e+00

Numeric fields use a relative tolerance of 1e-6 (1e-5 for the real-data regression) and an absolute tolerance of 1e-9. Strings and booleans must match exactly. The Paderborn dataset is optional; E10 is skipped when it is absent.
